# JULM — Interactive Art & Creative Coding Portfolio

A multi-project website hosting a collection of interactive art experiments and creative coding pieces, each exploring different visual concepts through browser-based interactivity.

## Projects

| Project | Description |
|---------|-------------|
| **aura-palette** | Interactive color/aura visualization using spot imagery |
| **color-quarry** | Color exploration tool with clickable object compositions |
| **covers-crosses-crowns** | Card-based game with 8 suits × 8 cards in 6 colors |
| **ghostrock-afterimage** | Visual afterimage effect using rock photography |
| **mineral-kaleidoscope** | Kaleidoscope visualization built from mineral spinner images |
| **not-apples** | Brick image gallery with interactive selection |
| **lectures** | Educational content featuring Zener card imagery and psychic research themes |
| **anticipated-properties** | Rock image exploration with light/dark toggle variants |

## Tech Stack

- **Vanilla HTML / CSS / JavaScript** — no framework dependencies
- **Custom animations** — CSS transitions and JavaScript-driven interactions
- **jQuery UI Touch Punch** — touch event support for drag interactions

## Running Locally

No build step required:

```bash
npx serve .
```

Each sub-project has its own `index.html` and can be navigated to directly. The root `index.html` serves as the portfolio hub.
